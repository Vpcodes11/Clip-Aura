
## 2026-05-21 - [Path Traversal in Download and Preview Endpoints]
**Vulnerability:** Found a critical path traversal vulnerability in `/api/download/{job_id}/{filename}` and `/api/preview/{job_id}/{filename}` endpoints. The `job_id` and `filename` path variables were directly concatenated to an `OUTPUT_DIR` path using pathlib (`OUTPUT_DIR / job_id / filename`). Although FastAPI/Starlette URL normalization handles `/../` in standard HTTP requests, un-normalized raw requests (like those generated by raw sockets or non-compliant clients using URL encoding like `%2f`) bypassed route-level normalization, enabling attackers to read arbitrary files via `../..` payloads.
**Learning:** Path parameters that represent file paths or IDs must be explicitly validated *after* all framework parsing/resolution. Never trust that URL routing alone is sufficient protection against Path Traversal, especially when using standard path concatenation on user input.
**Prevention:** Use `pathlib.Path.resolve().is_relative_to(BASE_DIR.resolve())` to explicitly enforce that the final resolved path strictly stays within the intended base directory.
